# Live Listener

Live Listener relays your earbud microphone to the other ear. Pick a sender bud and a receiver bud, then go live. The phone keeps the Bluetooth link open and plays the sender’s voice back through the earbuds.

## What you can do

- Choose which ear sends and which ear listens, from the home screen
- Go live only while a Bluetooth headset is connected
- Record during a live session, or leave it running without a recording
- Find saved takes in Takes
- Stop automatically if Bluetooth turns off or the earbuds disconnect, and keep a recording that was already in progress

The sender bud mixes the microphones it has into one wideband voice stream. The phone receives that stream and plays it through the earbuds.

## Requirements

- Node.js 24
- An Android phone and Bluetooth earbuds
- A development or release build. Expo Go does not include the native audio modules this app uses.

## Run

```bash
npm install
npx expo run:android
```

`npx expo start` launches the dev server after the native app is installed.

Typecheck with:

```bash
npx tsc --noEmit
```

## Project layout

- `src/screens` — home, live, earbuds, and takes
- `src/audio` — live relay, recording, and playback
- `modules/bluetooth-names` — connected headset names and the Android call route

`android/` and `ios/` are generated by Expo prebuild and are not part of this repo.
